# Changelog

## 0.1.0 (2026-10-09)

- Live log viewer for Maven / Spring Boot backends started by hand
- `springtail watch` follows the log file of a running app
- `springtail capture` saves piped console output for the viewer
- Single `springtail` command for PowerShell, cmd, Bash and zsh
- Spring Boot, Hibernate SQL and Maven lines parsed into levels
- Search, logger and level filters, pause, follow and expandable rows
- Dark theme with JetBrains Mono
- Develop/master release flow with version-bump hooks
